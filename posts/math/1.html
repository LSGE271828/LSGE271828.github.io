冲激函数与 Green 函数法

本文记录 δ(x)\delta(x)δ(x) 的一些基本应用，并尝试从 Dirichlet 积分、含冲激项的常微分方程，一路过渡到 Green 函数在 ODE 与 PDE 中的作用。

这几部分看起来分散，实际上有一条很自然的主线：把复杂对象分解到“点源”或“冲激”上，再研究系统对单个冲激的响应，最后通过叠加恢复一般情形。

1. 冲激函数

冲激函数 δ(x)\delta(x)δ(x) 常用来描述集中在一点上的理想化源。它并不是通常意义上的普通函数，而更适合作为广义函数理解。

例如，一个集中在 x=0x=0x=0 处、总量为 1 的点源，可以形式地写成

δ(x).\delta(x). δ(x).

它最重要的性质之一是筛选性质：

∫−∞∞f(x)δ(x−ξ) dx=f(ξ).\int_{-\infty}^{\infty} f(x)\delta(x-\xi)\,dx=f(\xi). ∫−∞∞​f(x)δ(x−ξ)dx=f(ξ).

从 Fourier 表示的角度，还可以形式地写成

δ(x−ξ)=12π∫−∞∞e±iω(ξ−x) dω.\delta(x-\xi) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{\pm i\omega(\xi-x)} \,d\omega. δ(x−ξ)=2π1​∫−∞∞​e±iω(ξ−x)dω.

参考书目：吴崇试《数学物理方程》

2. Dirichlet 积分

考虑经典积分

I=∫−∞∞sin⁡xx dx.I=\int_{-\infty}^{\infty}\frac{\sin x}{x}\,dx. I=∫−∞∞​xsinx​dx.

令

F(λ)=∫−∞∞sin⁡(λx)x dx.F(\lambda) = \int_{-\infty}^{\infty} \frac{\sin(\lambda x)}{x}\,dx. F(λ)=∫−∞∞​xsin(λx)​dx.

对参数 λ\lambdaλ 求导，有

F′(λ)=∫−∞∞cos⁡(λx) dx.F'(\lambda) = \int_{-\infty}^{\infty} \cos(\lambda x)\,dx. F′(λ)=∫−∞∞​cos(λx)dx.

利用冲激函数的 Fourier 表示，可以在广义函数意义下写成

F′(λ)=2πδ(λ).F'(\lambda)=2\pi\delta(\lambda). F′(λ)=2πδ(λ).

因此

F(λ)=2πH(λ)+C,F(\lambda)=2\pi H(\lambda)+C, F(λ)=2πH(λ)+C,

其中 H(λ)H(\lambda)H(λ) 为 Heaviside 阶跃函数。

又因为

F(−λ)=−F(λ),F(-\lambda)=-F(\lambda), F(−λ)=−F(λ),

所以对于 λ≠0\lambda\neq 0λ=0，

F(λ)=π sgn⁡(λ).F(\lambda)=\pi\,\operatorname{sgn}(\lambda). F(λ)=πsgn(λ).

于是

I=F(1)=π.I=F(1)=\pi. I=F(1)=π.

这个计算的有趣之处在于：原本的问题是一个反常积分，但通过引入参数 λ\lambdaλ，再对参数求导，积分问题被转化成了一个关于 F(λ)F(\lambda)F(λ) 的微分问题。

这种思路和常见的 Feynman 参数积分方法有一点相似：不直接硬算原积分，而是把它嵌入一个参数族中，再在变换后的问题里寻找更简单的结构。

3. 涉及冲激的 ODE

参考书目：吴大正《信号与系统》

继续考虑积分

G=∫−∞∞sin⁡2xx2+x+1 dx.G= \int_{-\infty}^{\infty} \frac{\sin^2 x}{x^2+x+1}\,dx. G=∫−∞∞​x2+x+1sin2x​dx.

定义辅助函数

F(λ)=∫−∞∞eiλxx2+x+1 dx.F(\lambda) = \int_{-\infty}^{\infty} \frac{e^{i\lambda x}}{x^2+x+1}\,dx. F(λ)=∫−∞∞​x2+x+1eiλx​dx.

由于

F′(λ)=∫−∞∞ix eiλxx2+x+1 dx,F'(\lambda) = \int_{-\infty}^{\infty} \frac{ix\,e^{i\lambda x}}{x^2+x+1}\,dx, F′(λ)=∫−∞∞​x2+x+1ixeiλx​dx,

以及

F′′(λ)=−∫−∞∞x2eiλxx2+x+1 dx,F''(\lambda) = -\int_{-\infty}^{\infty} \frac{x^2e^{i\lambda x}}{x^2+x+1}\,dx, F′′(λ)=−∫−∞∞​x2+x+1x2eiλx​dx,

于是有

−F′′(λ)−iF′(λ)+F(λ)=∫−∞∞eiλx dx.-F''(\lambda)-iF'(\lambda)+F(\lambda) = \int_{-\infty}^{\infty}e^{i\lambda x}\,dx. −F′′(λ)−iF′(λ)+F(λ)=∫−∞∞​eiλxdx.

利用

∫−∞∞eiλx dx=2πδ(λ),\int_{-\infty}^{\infty}e^{i\lambda x}\,dx = 2\pi\delta(\lambda), ∫−∞∞​eiλxdx=2πδ(λ),

得到一个含冲激项的 ODE：

−F′′(λ)−iF′(λ)+F(λ)=2πδ(λ).-F''(\lambda)-iF'(\lambda)+F(\lambda) = 2\pi\delta(\lambda). −F′′(λ)−iF′(λ)+F(λ)=2πδ(λ).

这一步很关键。原来的积分问题，被转化成了一个由冲激驱动的常微分方程问题。

在 λ≠0\lambda\neq0λ=0 时，方程退化为齐次方程

−F′′−iF′+F=0.-F''-iF'+F=0. −F′′−iF′+F=0.

结合 λ→±∞\lambda\to\pm\inftyλ→±∞ 时的衰减条件，以及 λ=0\lambda=0λ=0 处由 δ\deltaδ 项带来的导数跳跃条件，可以得到

F(λ)=2π3e−32∣λ∣e−i2λ.F(\lambda) = \frac{2\pi}{\sqrt3} e^{-\frac{\sqrt3}{2}|\lambda|} e^{-\frac{i}{2}\lambda}. F(λ)=3​2π​e−23​​∣λ∣e−2i​λ.

再利用

sin⁡2x=1−cos⁡2x2,\sin^2x=\frac{1-\cos2x}{2}, sin2x=21−cos2x​,

有

G=12[F(0)−Re⁡F(2)].G = \frac12 \left[ F(0)-\operatorname{Re}F(2) \right]. G=21​[F(0)−ReF(2)].

最终得到

G=π3(1−e−3cos⁡1).\boxed{ G= \frac{\pi}{\sqrt3} \left( 1-e^{-\sqrt3}\cos1 \right) }. G=3​π​(1−e−3​cos1)​.

这里已经可以看到一种很典型的数学物理方法：先通过变换把积分写成微分方程，再利用边界条件、连续性和跳跃条件求解。

4. Green 函数法在 ODE 中的应用

上面的含冲激 ODE，其实已经非常接近 Green 函数的思想。

设线性微分算子为

L,L, L,

我们希望求解

L[y](x)=f(x).L[y](x)=f(x). L[y](x)=f(x).

如果能够先找到一个函数 G(x,ξ)G(x,\xi)G(x,ξ)，使它满足

LxG(x,ξ)=δ(x−ξ),L_xG(x,\xi)=\delta(x-\xi), Lx​G(x,ξ)=δ(x−ξ),

并满足与原问题相同的边界条件，那么由于任意 f(x)f(x)f(x) 都可以形式地写成

f(x)=∫f(ξ)δ(x−ξ) dξ,f(x) = \int f(\xi)\delta(x-\xi)\,d\xi, f(x)=∫f(ξ)δ(x−ξ)dξ,

利用线性叠加便得到

y(x)=∫G(x,ξ)f(ξ) dξ.y(x) = \int G(x,\xi)f(\xi)\,d\xi. y(x)=∫G(x,ξ)f(ξ)dξ.

这里的 G(x,ξ)G(x,\xi)G(x,ξ) 就是 Green 函数。

换句话说，Green 函数描述的是：系统受到位于 ξ\xiξ 处的单位冲激后，在 xxx 处产生怎样的响应。

4.1 一个简单的一维例子

考虑整个实轴上的方程

y′′−a2y=f(x),a>0,y''-a^2y=f(x), \qquad a>0, y′′−a2y=f(x),a>0,

并要求 ∣x∣→∞|x|\to\infty∣x∣→∞ 时解衰减。

对应的 Green 函数满足

(d2dx2−a2)G(x,ξ)=δ(x−ξ).\left( \frac{d^2}{dx^2}-a^2 \right) G(x,\xi) = \delta(x-\xi). (dx2d2​−a2)G(x,ξ)=δ(x−ξ).

在 x≠ξx\neq\xix=ξ 时，

G′′−a2G=0.G''-a^2G=0. G′′−a2G=0.

结合无穷远处的衰减条件，可以写成

G(x,ξ)=Ce−a∣x−ξ∣.G(x,\xi) = C e^{-a|x-\xi|}. G(x,ξ)=Ce−a∣x−ξ∣.

为了确定常数 CCC，对 x=ξx=\xix=ξ 附近的小区间积分：

∫ξ−εξ+ε(G′′−a2G) dx=1.\int_{\xi-\varepsilon}^{\xi+\varepsilon} \left( G''-a^2G \right)\,dx = 1. ∫ξ−εξ+ε​(G′′−a2G)dx=1.

当 ε→0\varepsilon\to0ε→0 时，a2Ga^2Ga2G 项的积分趋于 0，于是得到导数跳跃条件

Gx(ξ+,ξ)−Gx(ξ−,ξ)=1.G_x(\xi^+,\xi)-G_x(\xi^-,\xi)=1. Gx​(ξ+,ξ)−Gx​(ξ−,ξ)=1.

由此可得

G(x,ξ)=−12ae−a∣x−ξ∣.G(x,\xi) = -\frac{1}{2a} e^{-a|x-\xi|}. G(x,ξ)=−2a1​e−a∣x−ξ∣.

因此原方程的解可以写成

y(x)=−12a∫−∞∞e−a∣x−ξ∣f(ξ) dξ.y(x) = -\frac{1}{2a} \int_{-\infty}^{\infty} e^{-a|x-\xi|} f(\xi)\,d\xi. y(x)=−2a1​∫−∞∞​e−a∣x−ξ∣f(ξ)dξ.

这就是一个标准的 Green 函数表示。

5. 从 ODE 到 PDE

Green 函数的思想并不局限于一维常微分方程。

例如在三维空间中，Poisson 方程可以写为

−Δu(r)=f(r).-\Delta u(\mathbf r)=f(\mathbf r). −Δu(r)=f(r).

如果寻找满足

−ΔG(r,r′)=δ(r−r′)-\Delta G(\mathbf r,\mathbf r') = \delta(\mathbf r-\mathbf r') −ΔG(r,r′)=δ(r−r′)

的基本解，那么在整个三维空间中有

G(r,r′)=14π∣r−r′∣.G(\mathbf r,\mathbf r') = \frac{1}{4\pi|\mathbf r-\mathbf r'|}. G(r,r′)=4π∣r−r′∣1​.

因此

u(r)=∫R3G(r,r′)f(r′) d3r′.u(\mathbf r) = \int_{\mathbb R^3} G(\mathbf r,\mathbf r') f(\mathbf r') \,d^3\mathbf r'. u(r)=∫R3​G(r,r′)f(r′)d3r′.

也就是说，一个一般的源 fff 可以被理解为无数个点源的叠加，而 Green 函数给出了每一个点源分别产生的响应。

这正是从一维 ODE 到高维 PDE 都反复出现的结构。

6. 与《信号与系统》的联系

到这里，Green 函数法和《信号与系统》中的冲激响应就可以直接联系起来了。

在线性时不变系统中，如果系统对单位冲激 δ(t)\delta(t)δ(t) 的响应为 h(t)h(t)h(t)，那么输入 x(t)x(t)x(t) 可以表示成

x(t)=∫−∞∞x(τ)δ(t−τ) dτ.x(t) = \int_{-\infty}^{\infty} x(\tau)\delta(t-\tau)\,d\tau. x(t)=∫−∞∞​x(τ)δ(t−τ)dτ.

由于系统具有线性和时不变性，输出就是

y(t)=∫−∞∞h(t−τ)x(τ) dτ=(h∗x)(t).y(t) = \int_{-\infty}^{\infty} h(t-\tau)x(\tau)\,d\tau = (h*x)(t). y(t)=∫−∞∞​h(t−τ)x(τ)dτ=(h∗x)(t).

这与 Green 函数表示

y(x)=∫G(x,ξ)f(ξ) dξy(x)=\int G(x,\xi)f(\xi)\,d\xi y(x)=∫G(x,ξ)f(ξ)dξ

在结构上几乎是同一件事。

因此，可以把这一整条思路概括成：

冲激函数
   ↓
点源 / 单位激励
   ↓
系统对单位激励的响应
   ↓
Green函数 / 冲激响应
   ↓
线性叠加
   ↓
一般输入或一般源的解

从 Dirichlet 积分开始，我们先用 δ\deltaδ 函数处理积分；随后把积分问题转化成含冲激项的 ODE；再进一步把“系统对冲激的响应”抽象成 Green 函数；最后，这一思想自然延伸到 PDE 和信号系统。

这也是我现在理解 Green 函数法最直观的一条路径：不是先把它当成一个孤立的公式，而是把它看作冲激分解、线性系统与数学物理方法共同形成的一种结构。
