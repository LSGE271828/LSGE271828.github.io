OpenCameraIQ：基于 DRUNet 与 VRN 的 Quad-Bayer 重建、真实图像去噪及 C++ 部署

本文记录一个面向移动端 Camera 成像链路的图像处理与 AI 工程项目 OpenCameraIQ。

项目并不单纯追求设计新的神经网络，而是希望从真实 Camera 数据出发，将 Quad-Bayer RAW、Remosaic、ISP、AI 图像恢复、真实噪声去除、ONNX/C++ 部署以及图像质量评价 串联成一套完整工程链路。

与单纯在 Python 中训练网络不同，本项目重点关注三个问题：

  1. 神经网络能否真正处理 Camera RAW/CFA 数据；
  2. AI 方法相对于传统 ISP 算法究竟带来了多少图像质量提升；
  3. 模型能否从 PyTorch 部署到 C++，并在延迟、内存和图像质量之间取得平衡。

项目最终形成两条主要 AI 路线：

路线 A：MIPI Quad-Bayer

Noisy Quad RAW
      ↓
RAW Packing
      ↓
Modified DRUNet
      ↓
Joint Remosaic + Denoise
      ↓
Bayer RAW
      ↓
ISP Pipeline
      ↓
RGB
      ↓
IQ Evaluation

以及：

路线 B：SIDD

Real Noisy sRGB

Preprocessing

PSNR / SSIM / Crop
      ↓
ONNX Runtime C++

两条路线分别对应 RAW 域计算摄影 与 真实手机图像去噪。

说明：本文实验部分给出的部分指标为项目设计阶段的预估值和目标区间，用于确定实验规模、消融实验和性能优化方向，并非已经获得的最终实验结果。正式项目结果将以实际运行数据替换。

3. 为什么需要处理 Quad-Bayer

普通 Bayer CFA 通常采用 RGGB 排列：

R G R G
G B G B
R G R G
G B G B

其最小周期为：

[
2\times2
]

而 Quad-Bayer 会将相邻同色像素组合：

R R G G
R R G G
G G B B
G G B B

这样可以在低照度情况下执行 2×2 Pixel Binning。

例如：

R1 R2
R3 R4

可以形成：

[
R_

\frac{R_1+R_2+R_3+R_4}{4}
]

从而牺牲一定空间分辨率，提高有效信噪比。

但在光照充足的情况下，我们希望使用 Sensor 的完整空间分辨率，因此需要执行：

[
Quad\ CFA
\rightarrow
Standard\ Bayer\ CFA
]

这一过程就是 Remosaic。

4. Remosaic 为什么不是简单的数据重排

假设 Quad CFA 某个位置实际采集：

[
R(x,y)
]

但目标 Bayer CFA 在相同位置要求：

[
G(x,y)
]

Sensor 并没有直接获得这个绿色采样。

因此算法需要估计：

[
\hat G(x,y)

f(\mathcal N(x,y))
]

其中：

[
\mathcal N(x,y)
]

表示该位置附近的空间与颜色信息。

所以 Remosaic 本质上是一个 缺失颜色采样恢复问题。

传统算法通常依赖：

  • Local Gradient
  • Edge-aware Interpolation
  • Directional Interpolation
  • Color Difference
  • Local Correlation

例如可以计算：

[
D_H=
|I(x-1,y)-I(x+1,y)|
]

以及：

[
D_V=
|I(x,y-1)-I(x,y+1)|
]

然后根据局部梯度选择插值方向。

这种方法计算量较小，但面对复杂纹理时容易产生：

  • False Color
  • Zipper Artifact
  • Moiré
  • Edge Blur
  • Detail Loss

这也是引入神经网络的重要原因。

5. MIPI Quad-Bayer 数据构建

MIPI Quad-Bayer 数据可以形成：

[
Quad\rightarrow Bayer_{GT}
]

严格配对。

项目主要考虑三个噪声等级：

Quad 0 dB
Quad 24 dB
Quad 42 dB

分别与对应 Bayer Ground Truth 配对。

因此可以建立训练样本：

[
(X_i,Y_i)
]

其中：

[
X_i=Quad_i
]

[
Y_i=Bayer_{GT,i}
]

从而将问题定义为监督学习：

[
f_\theta(X_i)
\approx
Y_i
]

6. 为什么把 DRUNet 放到 MIPI Quad-Bayer

原始 DRUNet 更常用于：

[
Noisy\ RGB
\rightarrow
Clean\ RGB
]

但它具有一个非常适合图像恢复的结构特点：

[
U\text{-}Net
+
Residual\ Block
+
Noise\ Level\ Map
]

高分辨率浅层特征可以保留：

[
Edge,\ Texture,\ Detail
]

深层特征则拥有更大的感受野。

这对于 Remosaic 很有价值，因为 CFA 重建同时需要：

  • 局部像素关系；
  • 边缘方向；
  • 周围颜色相关性；
  • 更大尺度纹理上下文。

因此本项目并不直接使用 RGB DRUNet 的公开权重，而是：

[
\boxed{
保留DRUNet思想
+
修改RAW输入输出
+
在MIPI数据上重新训练
}
]

将它改造成一个 Quad RAW Joint Remosaic + Denoise Network。

7. RAW Packing

直接将：

[
H\times W\times1
]

的 CFA RAW 当作普通灰度图输入网络并不理想。

因为像素的物理意义由 CFA 位置决定。

因此首先执行 Quad CFA Packing。

Quad CFA 的最小周期为：

[
4\times4
]

可以通过 Pixel Unshuffle 将：

[
H\times W\times1
]

转换为：

[
\frac H4
\times
\frac W4
\times16
]

即：

[
X_

P(X_{quad})
]

这样每个 Channel 都对应 CFA 周期中的固定位置。

相比直接输入单通道 RAW，网络更容易学习：

[
CFA\ Position
\leftrightarrow
Color\ Response
]

之间的关系。

9. Noise Level Map

不同噪声等级下，最佳恢复强度并不相同。

因此可以增加 Noise Level Map：

[
M_\sigma
]

输入变成：

[
X=
Concat(X_{packed},M_\sigma)
]

网络学习：

[
\hat Y=
f_\theta(X,\sigma)
]

这样一个模型就可以处理多个噪声等级，而不是分别训练三个网络。

10. Loss Function

Baseline 首先采用：

[
L_

|\hat Y-Y|_1
]

L1 相比纯 MSE 通常更有利于减少过度平滑。

但 Remosaic 特别关注边缘和高频纹理，因此进一步加入 Edge Loss：

[
L_

|
\nabla\hat Y-\nabla Y
|_1
]

同时加入颜色/结构约束：

[
L_{structure}
]

最终设计：

[
L=
L_{pixel}
+
\lambda_eL_{edge}
+
\lambda_sL_{structure}
]

初始可以设置：

[
\lambda_e=0.1
]

[
\lambda_s=0.05
]

随后通过消融实验确定。

27. C++ 性能优化

对于：

[
4000\times3000
]

[

\approx36MB
]

因此项目重点优化：

  • Buffer Reuse
  • Move Semantics
  • Memory Pool
  • Zero Copy
  • Cache Locality
  • SIMD
  • Multithreading

优化原则是：

[
Profile
\rightarrow
Locate\ Bottleneck
\rightarrow
Optimize
]

而不是一开始就盲目增加线程。

ONNX Runtime+C++

整个项目关注的核心并不是单纯追求更大的网络，而是：

[
\boxed{

+
传统ISP
+
深度图像恢复
+
C++工程部署
+
IQ调优
